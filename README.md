# CMPE-131---Sec-05 — SpartIN

SpartIN helps SJSU transfer students meet through small events: swipe right to join, left to pass, or host your own.

| Part | Docs |
| --- | --- |
| MVP plan (scope, design, recommendations) | [`docs/MVP_PLAN.md`](docs/MVP_PLAN.md) |
| Frontend (React web app) | [`frontend/README.md`](frontend/README.md) |
| Backend API | [`backend/README.md`](backend/README.md), [`docs/backend/`](docs/backend/) |

Quick start: start Postgres, then `cd backend && npm install && npm run db:deploy && npm run db:seed && npm run dev`, and in a second terminal `cd frontend && npm install && npm run dev` → http://localhost:8081
